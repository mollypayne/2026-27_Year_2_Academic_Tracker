A relational SQL database University Tracker for the 2026-27 Academic year.

Designed to track university modules, assessments, grades, deadlines, study sessions, activities and time spent.

## Currently implemented:
- Relational database design
- Primary and foreign keys
- Data integrity constraints
- NULL handling
- Basic filtering and sorting
